# SOP-001: Vehicle Engine Fault Diagnosis (Ashok Leyland Stallion)

1. If engine cranks but does not start, check fuel gauge and fuel shut-off valve.
2. Inspect battery terminals for corrosion; voltage must read >= 24V across terminals.
3. Check air filter clog indicator; clean or replace filter if red band shows.
4. Bleed fuel system: loosen bleed screw on fuel filter, pump primer until bubble-free fuel flows.
5. If engine overheats above 95C, stop vehicle, idle 2 min, then shut off; check coolant level and fan belt.
6. Record fault, action taken, and meter reading in vehicle log book (IAFZ-2096A).
7. Escalate to EME workshop if fault repeats twice after field fix.

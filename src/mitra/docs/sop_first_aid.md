# SOP-005: Field First Aid (Casualty Evacuation)

1. Stop bleeding first: apply pressure dressing; tourniquet only if limb bleed uncontrolled.
2. Check airway and breathing; place unconscious casualty in recovery position.
3. Record casualty details on field medical card: time, injury type, treatment given.
4. Request CASEVAC with 9-liner format: location, callsign, casualties, LZ security.
5. Do not move suspected spinal injury unless under fire; stabilise neck first.

# SOP-003: Radio Set Start-Up (VHF Manpack)

1. Connect battery and antenna before switching on; never transmit without antenna.
2. Set frequency as per CEOI card; confirm squelch at mid position.
3. Radio check format: "<callsign> radio check, over" - reply with readability 1-5.
4. Change battery when low-batt LED blinks red; average life 12 hours at 1:9 TX:RX.
5. On jamming, switch to alternate frequency per CEOI and reduce transmission time.
6. Log all transmissions with DTG in radio log register.

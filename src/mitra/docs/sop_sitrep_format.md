# SOP-002: SITREP Format (Field Unit)

1. SITREP header: DTG (date-time group), sender callsign, classification.
2. Line 1 - Own position: grid reference (8-figure) and altitude.
3. Line 2 - Enemy activity: direction, distance, strength observed in last 24h.
4. Line 3 - Own casualties and equipment state: fit / unfit / under repair.
5. Line 4 - Logistics: ammo, fuel, ration state in days; urgent demands flagged.
6. Line 5 - Commander's intent for next 24h in one sentence.
7. Transmit SITREP every 6 hours or immediately on contact; keep under 150 words.
